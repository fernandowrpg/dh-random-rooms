Patamares

O peso é relativo aos outros encontros do mesmo patamar. Como 2d12 somados formam uma curva, a chance real é a mais próxima possível do pedido; escolha um patamar para ver as duas.

Como rolar

Role 2d12, um como dado de Esperança e outro como dado de Medo. A soma define a sala. O dado mais alto define como o grupo entra nela, e o efeito muda com o patamar:

  • Esperança maior (45,8%): a sala favorece o grupo.
  • Medo maior (45,8%): a sala favorece o mestre.
  • Dados iguais (8,3%): crítico.

Os textos abaixo são uma regra da casa; edite à vontade. Orçamento de combate, Dificuldade, dano e limiares seguem o livro básico.

Ordem das faixas

Em 2d12 as somas do meio (perto de 13) saem muito mais que as das pontas. Deixar os raros nas pontas é o que mais aproxima a chance real do peso pedido.

Macro para o Foundry

  1. No Foundry, crie uma macro do tipo Script e cole o código abaixo.
  2. Execute como mestre. Ela cria uma Tabela de Rolagem 2d12 por patamar na pasta “Salas de Encontro” e a macro Rolar Sala de Encontro.
  3. Use a macro criada para rolar: ela mostra a sala e o efeito de Esperança/Medo no chat.

Executar de novo substitui as tabelas de mesmo nome dentro dessa pasta.
